# Program Sharing Feature Overview

## What is Program Sharing?

Program Sharing is a feature that allows instructors and administrators to generate special links for training programs and share them on social media platforms like Facebook, Twitter, LinkedIn, and WhatsApp. When users click these links, they gain access to the program with a streamlined enrollment experience.

---

## How Does It Work?

### For Admins/Instructors
1. Navigate to any program you manage
2. Click the "Generate Share Link" button
3. Copy the link and share it anywhere

### For Users
1. Click a shared program link (usually from social media)
2. If you're a new user, you'll be asked to sign up (with the program already selected)
3. If you already have an account, you'll be asked to log in
4. After logging in, the program details appear automatically
5. Click "Enroll" to join the program

---

## Benefits of Program Sharing

- **Easy Enrollment**: One click takes you directly to program enrollment
- **No Search Required**: The program is already selected for you
- **Faster Sign-Up**: New users don't need to search for the program
- **Social Media Friendly**: Links display beautifully on all social platforms
- **Track Interest**: See analytics on how many people clicked your shared links

## Common Scenarios

### Scenario 1: Promoting a New Program
An instructor wants to reach students on social media:
1. Creates the program in the system
2. Generates a share link
3. Posts the link on LinkedIn and Facebook
4. Students see the post, click the link, and enroll

### Scenario 2: Quick Enrollment
A student sees a program shared on Facebook:
1. Clicks the link
2. Logs in with their existing account
3. Program details appear automatically
4. Clicks "Enroll" - done!

### Scenario 3: New Student Registration
A person discovers a program on WhatsApp:
1. Clicks the link
2. The program is already selected
3. Signs up with their information
4. Automatically enrolls in the program

---

## What Happens After I Enroll?

After you successfully enroll in a program through a shared link:
- You'll see a confirmation message
- The program appears in your dashboard
- You can start accessing program materials
- The share link context is cleared (won't affect your next actions)
