## 📋 Quick Reference Card #1: For Admins - Generating & Sharing Links

### Generate a Share Link (2 Minutes)

```
1. Log in to your admin account
2. Go to Programs → [Select Program]
3. Click "Generate Share Link" button
4. Click "Copy to Clipboard"
5. Paste link in social media, email, or message
```

### Share Link URL Format
```
https://yourapp.com/share?program_id=[UUID]
```

### Social Media Platforms

| Platform | Time to Share | Best For |
|----------|---------------|----------|
| Facebook | 2 min | Large audience, communities |
| Twitter | 2 min | Real-time, professionals |
| LinkedIn | 3 min | B2B, career advancement |
| WhatsApp | 1 min | Direct contacts, groups |
| Email | 5 min | Newsletters, mailing lists |

### Quick Tips
✅ Share multiple times across different platforms
✅ Use different messages for different platforms
✅ Best times: Morning (8-9am), Lunch (12-1pm), Evening (5-7pm)
✅ Space posts out over days/weeks

### Sample Post Ideas

**Facebook**:
```

#Training #CareerGrowth
```

**Twitter**:

**LinkedIn**:

## 📋 Quick Reference Card #2: For Users - Following a Shared Link

### When You Click a Shared Link

```
New User?
1. Link → Signup Page
2. Program pre-selected ✓
3. Fill in your info
4. Click "Sign Up"
5. Automatically enrolled!

Existing User?
1. Link → Login Page
2. Enter your credentials
3. Program details auto-open
4. Click "Enroll"
5. Enrolled!
```

### What to Expect

| Stage | What You See | What To Do |
|-------|-------------|-----------|
| Link Click | Loading spinner | Wait... |
| Validation | Brief pause | Your program is being verified |
| Redirect | Login or Signup form | Fill in your details |
| Program Modal | Program details appear | Review and click "Enroll" |
| Confirmation | Success message | ✅ You're enrolled! |

### Troubleshooting Fast

**Problem**: Link not working
**Fix**: Refresh page → Clear cache → Try new browser

**Problem**: Can't log in
**Fix**: Use "Forgot Password" → Check email → Reset password

**Problem**: Don't see enrollment button
**Fix**: Enable pop-ups → Disable ad blockers → Refresh page

## 📋 Quick Reference Card #3: Mobile Device Checklist

### Before Using on Mobile

✅ Modern browser (Chrome, Firefox, Safari, Edge)
✅ Latest version of browser
✅ JavaScript enabled
✅ Pop-ups allowed
✅ Stable internet connection
✅ Adequate storage (30MB minimum)

### If Having Mobile Issues

1. **Close and restart browser**
2. **Clear cache** (Settings → Apps → Browser → Storage)
3. **Try a different browser** (if currently using default)
4. **Try desktop version** (if available)
5. **Contact support** if still having issues

### Mobile Tips

- **Landscape mode** often works better for forms
- **Tap twice** to zoom in on small buttons
- **Use mobile app** for better experience (if available)
- **Connect to WiFi** if using cellular (faster loading)

## 📋 Quick Reference Card #4: Troubleshooting Decision Tree

```
Something not working?

├─ Link won't open?
│  ├─ Is link correct? → Copy from admin again
│  ├─ Is program active? → Ask admin
│  └─ Wrong browser? → Try Chrome/Firefox
│
├─ Can't log in?
│  ├─ Forgot password? → Click "Forgot Password"
│  ├─ Wrong email? → Try other emails you use
│  └─ Account locked? → Wait 15 min or contact support
│
├─ See "Permission Denied"?
│  ├─ Program restricted? → Ask instructor
│  ├─ Program full? → Check waitlist
│  └─ Need prerequisites? → Complete them first
│
├─ Modal won't open?
│  ├─ Pop-ups blocked? → Enable pop-ups
│  ├─ Ad blocker on? → Disable it
│  └─ Browser too old? → Update browser
│
├─ Enrollment failed?
│  ├─ Already enrolled? → Check dashboard
│  ├─ Form incomplete? → Fill all fields
│  └─ System error? → Try again in 5 minutes
│
└─ Still stuck?
   └─ Contact support → support@yourapp.com
```

## 📋 Quick Reference Card #5: Admin Analytics Checklist

### Monitor Your Link Performance

**Weekly**:
- [ ] Check total click count
- [ ] Review top platforms
- [ ] Note enrollment rate

**Monthly**:
- [ ] Compare performance across platforms
- [ ] Identify best messaging
- [ ] Plan next month's promotion

**Key Metrics**:
- **Click-Through Rate**: Total clicks on link
- **Enrollment Rate**: % of clicks that lead to enrollment
- **Drop-off Points**: Where people leave process
- **Best Platform**: Highest conversion platform
- **Peak Times**: When people click most

### Optimization Tips

**Low Click Rate?**
→ Share more frequently
→ Try different messaging
→ Use more engaging images

**Clicks but Few Enrollments?**
→ Program details unclear
→ Make enrollment easier
→ Check prerequisites

**High Enrollment Rate?**
→ Share more!
→ Replicate messaging
→ Try new platforms

## 📋 Quick Reference Card #6: Browser Compatibility

### Supported Browsers (Recommended Versions)

| Browser | Min Version | Status |
|---------|------------|--------|
| Chrome | 80+ | ✅ Full Support |
| Firefox | 75+ | ✅ Full Support |
| Safari | 13+ | ✅ Full Support |
| Edge | 80+ | ✅ Full Support |

### Known Issues by Browser

**Chrome**:
- ✅ No known issues
- Best browser for this feature

**Firefox**:
- Some pop-up blocker issues
- Solution: Disable blocking for this domain

**Safari**:
- Older versions (pre-13) have issues
- Solution: Update to latest Safari

**Edge**:
- ✅ No known issues
- Works same as Chrome

### Quick Browser Fix

```
1. Update your browser
2. Clear cache (Settings → Privacy → Clear data)
3. Disable extensions
4. Try incognito/private mode
5. Try different browser if issues persist
```

## 📋 Quick Reference Card #7: Quick Support Contact Guide

### When to Contact Support

**Contact Support If**:
- ✅ Troubleshooting didn't work
- ✅ Issue persists after 30 minutes
- ✅ Error message with code
- ✅ Multiple devices affected
- ✅ Unsure about feature

**DON'T Contact Support For**:
- ❌ General feature questions → Check FAQ
- ❌ How-to guides → See documentation
- ❌ Password reset → Use forgot password link

### Support Channels

**📧 Email** (Best for detailed issues)
```
support@yourapp.com
Response: 24 hours
Include: Email, problem description, screenshot, what you tried
```

**💬 Live Chat** (Best for quick help)
```
In-app chat button
Response: 30 min (business hours)
Best for: Quick troubleshooting
```

**📞 Phone** (If available)
```
1-800-SUPPORT
Hours: [Your hours]
Best for: Complex issues, urgent help
```

### Information to Provide

Always include:
1. Your account email
2. What you were trying to do
3. What error you saw
4. What you already tried
5. Your device/browser info

## 📋 Quick Reference Card #8: Accessibility Quick Guide

### Using Program Sharing with Accessibility Needs

**For Screen Readers**:
- ✅ Fully compatible with NVDA, JAWS
- ✅ All buttons labeled
- ✅ Clear heading structure

**For Keyboard Users**:
- ✅ Tab to navigate
- ✅ Enter to select
- ✅ No mouse required

**For Low Vision**:
- ✅ Zoom up to 200% (Ctrl/Cmd + +)
- ✅ High contrast mode supported
- ✅ Text is readable at all sizes

**For Color Blindness**:
- ✅ Not color-dependent
- ✅ Icons + text labels
- ✅ Clear contrast

### Accessibility Tips

```
Chrome:
Settings → Accessibility → Read aloud

Firefox:
Add-ons → Screen reader → NVDA

Safari:
System Preferences → Accessibility

General:
Ctrl/Cmd + + = Zoom in
Ctrl/Cmd + - = Zoom out
Tab = Navigate
Alt = Keyboard navigation
```
