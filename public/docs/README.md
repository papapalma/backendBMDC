## 🔍 Key Features Explained

### Share Link
A unique URL that embeds a program reference, allowing users to access the program with pre-selected enrollment.

**Related Sections**:
- Admin Guide: How to generate
- Trainee Guide: How to use
- Feature Overview: How it works

### Program Pre-Selection
When a user clicks a shared link, the program is automatically selected in their enrollment flow.

**Related Sections**:
- Trainee Guide: Signup flow
- Feature Overview: Benefits

### Auto-Open Modal
After login through a shared link, the program details automatically display in a modal window.

**Related Sections**:
- Trainee Guide: Joining through modal
- Troubleshooting: Modal not opening

### Source Tracking
The system tracks enrollment source (social_share, direct, admin_assigned) to understand conversion paths.

**Related Sections**:
- Admin Guide: Analytics section
- Feature Overview: Benefits

## ⚠️ Important Notes

### Data Privacy
- Shared links are public URLs
- Anyone with the link can access the program enrollment
- No personal data is exposed through the link
- User data is protected with encryption

### Security
- Links are permanent (don't expire)
- Links cannot be customized (always the same format)
- Program ID is visible in the URL (intentional design)
- All backend processes are security-verified

### Browser Compatibility
- Works on all modern browsers (Chrome, Firefox, Safari, Edge)
- Requires JavaScript enabled
- Works on mobile browsers
- Older browsers may have limited functionality
