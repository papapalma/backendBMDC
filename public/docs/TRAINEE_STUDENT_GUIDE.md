## What You'll Experience

### When You Click a Shared Program Link

**Here's the typical flow:**

1. **Link Click** → You click a program link from social media
2. **Loading** → The app briefly validates the program
3. **Redirect** → You're guided to the next step based on your status:
   - **Not logged in?** → Sign up or Log in
   - **Already logged in?** → Program details appear automatically
4. **Enrollment** → You see the program details and can enroll
5. **Confirmation** → Success! You're now enrolled in the program

### Key Feature: Program Pre-Selection

When you access the app through a shared link, the program is automatically selected for you. You won't need to search for it or scroll through a list. This saves you time and gets you to enrollment faster.

## For New Users

### Step 1: Click the Shared Link

You've received a shared program link (probably from social media, email, or a message). Here's what to do:

**Click the Link**
- Simply click on the link
- Wait a moment while the system loads
- You'll be taken to the signup page

**What to Expect**
- A brief loading screen
- Then the signup form appears with the program already selected
- No need to search for the program

### Step 2: The Signup Form

The signup form will appear with the program pre-selected. Here's what you'll see:

**Section 1: Program Information**
```
📚 You're signing up to enroll in:
   [Program Name]
   [Program Duration] | [Start Date]
   [Brief Description]
```

You can:
- ✅ Keep this program selected (recommended)
- 🔄 Click "Change Program" to select a different one
- ℹ️ Click "View Details" to learn more about the program

**Section 2: Your Information**

Fill in your personal details:
- **Full Name**: Enter your first and last name
- **Email Address**: Enter your email (where login links will be sent)
- **Password**: Create a secure password (minimum 8 characters)
- **Confirm Password**: Re-enter your password

**Section 3: Optional Information**

- Phone number (optional)
- Country/Region (optional)
- Previous experience level (optional)

### Step 3: Review Terms (if applicable)

You may see:
- Terms of service
- Privacy policy
- Program-specific terms

**Read and confirm** these by checking the boxes if required.

### Step 4: Complete Signup

**Click "Sign Up"**
- The app processes your information
- Creates your new account
- Automatically enrolls you in the pre-selected program

**What You'll See Next**
- A confirmation message: "Welcome! You're successfully enrolled."
- A redirect to the program page
- Your program dashboard with program materials

**Troubleshooting Signup Issues**:
- [See Troubleshooting Section](#troubleshooting)

## For Existing Trainees

### Step 1: Click the Shared Link

You see a shared program link from an instructor or colleague.

**Click the Link**
- Click the link from social media, email, or message
- A brief loading screen appears
- You're redirected to the login page

### Step 2: Login

**See the Login Form**
```
🔐 Login
To continue with program enrollment, please login
```

**Enter Your Credentials**
- **Email/Username**: Enter the email you used when registering
- **Password**: Enter your password

**Login Options**
- 📧 Email/Password (shown above)
- 🔑 If you forgot your password, click "Forgot Password?"
- 📱 If available, other login methods may be offered

### Step 3: Two-Factor Authentication (if enabled)

Some accounts may require additional security:

**If You See a Code Request**
- Check your email for a verification code
- Or check your authenticator app (if you set one up)
- Enter the code in the prompt
- Click "Verify"

### Step 4: After Login - Program Page

**Automatic Redirect**
- After login, you're automatically taken to the program page
- The program is already selected and displayed
- You don't need to search or navigate

**What You See**
- Program title and description
- Program duration and schedule
- Enrollment requirements
- A Program Details Modal (usually auto-opened)
- An "Enroll" button

## The Enrollment Process

### Step 1: Review Program Details

When the program modal appears (either auto-opened or manually), you'll see:

**Program Information Card**
```
📚 Program: [Program Name]
⏱️  Duration: [X weeks/months]
📅 Start Date: [Date]
👨‍🏫 Instructor: [Instructor Name]
📝 Description: [Full program description]
```

**Program Details Include**
- ✅ What you'll learn
- ✅ Prerequisites (if any)
- ✅ Time commitment required
- ✅ Instructor information
- ✅ Number of enrolled students
- ✅ Program status (Active, Upcoming, Full, etc.)

### Step 2: Check if You Meet Requirements

**Look For Any Prerequisites**
- Does the program require prior experience? (You can typically see this in the details)
- Do you need to complete another program first?
- Are there any skill level requirements?

**If You're Not Sure**
- 💬 Send a message to the instructor
- ❓ Look in the FAQ section
- 📞 Contact support

### Step 3: Make Your Decision

You have two options:

**Option A: Enroll Now** ✅
1. Click the "Enroll" button in the modal
2. Wait for confirmation
3. You're now enrolled!

**Option B: Don't Enroll Yet** ❌
1. Click "Close" or "Cancel"
2. The program context is cleared
3. The program appears in your available programs list for later
4. You can enroll through the program catalog anytime

### Step 4: Confirmation

**Upon Successful Enrollment**
```
✅ Success!
You're now enrolled in [Program Name]

Your program starts on [Date]
You can access all materials in your Dashboard
```

**Next Steps**
- Check your email for enrollment confirmation
- Go to your Dashboard to see the program
- Access program materials and begin learning

## What Happens After Enrollment

### Immediately After

**Confirmation Screen**
- You see: "✅ Successfully Enrolled!"
- Brief message confirming your enrollment
- Redirect to program dashboard or materials page

**Email Confirmation**
- Check your email (usually within minutes)
- Confirmation of your enrollment
- Link to access program materials
- Instructor contact information

### In Your Dashboard

**Program Now Visible**
- Your new program appears in your "Active Programs" list
- You can see program schedule, materials, and assignments
- Notifications about program updates appear here

**Access Program Materials**
- Click on the program to see all content
- Access lessons, resources, and assignments
- Submit work if required
- Communicate with instructors

### Important to Know

**The Share Context is Cleared**
- After enrollment, the shared program link context is removed
- This doesn't affect your enrollment
- You keep all access to the program permanently
- The program stays in your dashboard

**No Further Action Needed**
- You've successfully completed the enrollment process
- Start accessing program materials immediately
- Your account remains active as long as you're registered

## Troubleshooting

### Issue: Link Not Working / Page Not Found

**What This Looks Like**
```
❌ Error: Page Not Found
The program could not be found.
```

**Possible Causes & Solutions**

1. **Program No Longer Active**
   - The program may have been archived or completed
   - **Solution**: Contact the instructor or check the programs list
   
2. **Link Was Entered Incorrectly**
   - The link may have been truncated or modified
   - **Solution**: Ask for the link to be shared again
   
3. **Using Outdated Browser**
   - Your browser may not support the latest features
   - **Solution**: Update your browser or try Chrome/Firefox
   
4. **Connection Issue**
   - Your internet connection may be unstable
   - **Solution**: Refresh the page or try again in a few minutes

### Issue: "You Don't Have Permission to Access This Program"

**What This Looks Like**
```
⚠️ Access Denied
You don't have permission to access this program.
```

**Possible Causes & Solutions**

1. **Program is Restricted**
   - The program may only be open to certain users
   - **Solution**: Contact the instructor to request access
   
2. **Program Enrollment Closed**
   - The program may have reached capacity
   - **Solution**: Ask the instructor if there's a waitlist or future offering
   
3. **You're Logged Into Wrong Account**
   - You might be logged into a different account
   - **Solution**: Log out and log back in with the correct account
   
4. **Account Restrictions**
   - Your account might have login restrictions
   - **Solution**: Contact support to verify your account status

### Issue: Login Failed / Can't Access My Account

**What This Looks Like**
```
❌ Login Failed
Invalid email or password. Please try again.
```

**Possible Causes & Solutions**

1. **Wrong Password**
   - You may have typed your password incorrectly
   - **Solution**: Use "Forgot Password" to reset it
   
2. **Wrong Email**
   - You might be using a different email than you registered with
   - **Solution**: Try other email addresses you might have used
   
3. **Account Locked**
   - Your account may be temporarily locked after failed attempts
   - **Solution**: Wait 15 minutes and try again, or contact support
   
4. **Account Not Activated**
   - Your account might not be fully verified
   - **Solution**: Check your email for activation link, or request a new one

### Issue: Signup Failed / Can't Create Account

**What This Looks Like**
```
❌ Signup Failed
Please check the form for errors and try again.
```

**Possible Causes & Solutions**

1. **Email Already Exists**
   - The email might already be registered
   - **Solution**: Log in instead, or use a different email
   
2. **Password Too Weak**
   - Password may not meet security requirements
   - **Solution**: Use a password with uppercase, lowercase, numbers, and symbols
   
3. **Required Fields Empty**
   - Some required information wasn't filled in
   - **Solution**: Fill in all fields marked with * (asterisk)
   
4. **Invalid Email Format**
   - The email format might be incorrect
   - **Solution**: Double-check the email (e.g., name@email.com)

### Issue: Enrollment Failed / Couldn't Complete Enrollment

**What This Looks Like**
```
❌ Enrollment Failed
Unable to complete your enrollment. Please try again.
```

**Possible Causes & Solutions**

1. **Program at Capacity**
   - All available spots filled
   - **Solution**: Contact instructor about waitlist options
   
2. **Missing Prerequisites**
   - You don't meet program requirements
   - **Solution**: Complete required prerequisites first
   
3. **Temporary System Issue**
   - The system may have encountered a problem
   - **Solution**: Wait a minute and try again
   
4. **Duplicate Enrollment**
   - You might already be enrolled
   - **Solution**: Check your programs list to confirm you're already enrolled

### Issue: Modal Doesn't Auto-Open / Can't See Program Details

**What This Looks Like**
- You're on the program page, but no details are showing
- You have to manually click to see program information

**Possible Causes & Solutions**

1. **JavaScript Disabled**
   - Your browser may have JavaScript disabled
   - **Solution**: Enable JavaScript in browser settings
   
2. **Browser Extension Interference**
   - A browser extension might be blocking the modal
   - **Solution**: Temporarily disable extensions and try again
   
3. **Browser Cache**
   - Old cached data might be causing issues
   - **Solution**: Clear browser cache and refresh the page
   
4. **Pop-up Blocker**
   - Your pop-up blocker might be blocking the modal
   - **Solution**: Add the site to your browser's exception list

### Issue: Program Disappeared / Can't Find Enrolled Program

**What This Looks Like**
```
You enrolled in a program through a shared link,
but now it doesn't appear in your dashboard.
```

**Possible Causes & Solutions**

1. **Program Archived by Instructor**
   - The instructor may have archived the program
   - **Solution**: Contact instructor about program status
   
2. **Course Ended**
   - The program may have naturally concluded
   - **Solution**: Look in "Completed Programs" or "Archived Programs"
   
3. **Wrong Account**
   - You might be logged into a different account
   - **Solution**: Check which account you're using
   
4. **Enrollment Cancelled**
   - Your enrollment may have been cancelled
   - **Solution**: Contact instructor or support for explanation

### Issue: Slow Loading / Page Takes Too Long

**What This Looks Like**
- The shared link takes a long time to process
- Loading spinner displays for more than 10 seconds

**Possible Causes & Solutions**

1. **Slow Internet Connection**
   - Your connection may be unstable
   - **Solution**: Check your connection, move closer to router, or try later
   
2. **Busy Server**
   - System may be under heavy load
   - **Solution**: Wait a few moments and try again
   
3. **Large Program Details**
   - Program may have lots of materials to load
   - **Solution**: Wait for full load, or reduce browser tabs
   
4. **Large Media Files**
   - Program may include large images or videos
   - **Solution**: Ensure adequate bandwidth, or try on better connection

### Issue: Can't Copy Link / Browser Compatibility

**What This Looks Like**
```
You're trying to share a link, but copy-to-clipboard isn't working.
```

**Possible Causes & Solutions**

1. **Outdated Browser**
   - Your browser doesn't support copy functionality
   - **Solution**: Update your browser to latest version
   
2. **HTTPS Required**
   - Copy-to-clipboard requires secure connection
   - **Solution**: Ensure you're on https:// (not http://)
   
3. **Browser Permissions**
   - Browser may require permission for clipboard access
   - **Solution**: Allow clipboard permissions when prompted
   
4. **Manual Workaround**
   - If copy function fails, manually select and copy the URL
   - **Solution**: Triple-click the URL bar to select all, then Ctrl+C (Cmd+C on Mac)

### Issue: Two-Factor Authentication Not Working

**What This Looks Like**
```
You're not receiving the verification code,
or entering it isn't working.
```

**Possible Causes & Solutions**

1. **Email Not Received**
   - The code email might be delayed or in spam folder
   - **Solution**: Check spam/junk folder, or wait a few minutes
   
2. **Code Expired**
   - The code may have expired (usually 10-15 minutes)
   - **Solution**: Request a new code
   
3. **Typo in Code**
   - You may have mistyped the code
   - **Solution**: Copy-paste the code instead of typing
   
4. **Authenticator App Issue**
   - If using authenticator app, system time may be incorrect
   - **Solution**: Check your device's system time is correct

### General Troubleshooting Tips

**Clear Your Browser Cache**
1. Open browser settings
2. Go to Privacy/History
3. Click "Clear browsing data"
4. Select "Cookies and cached images"
5. Choose "All time"
6. Click "Clear data"
7. Refresh the page

**Try a Different Browser**
- If issues persist, try Chrome, Firefox, Safari, or Edge
- Different browser may work better with your system

**Disable Browser Extensions**
1. Open browser extensions/add-ons
2. Temporarily disable all extensions
3. Try using the link again
4. Re-enable extensions one by one to find the culprit

**Check Your Internet Connection**
- Open another website to confirm connection
- Restart your router if connection is slow
- Use a different network if available

**Check Your Device**
- Restart your computer/phone
- Ensure your device has enough storage
- Check that your device time/date is correct
